# Periodic Puzzle

A chemistry puzzle game where players combine ions and elements to form compounds.

## Features

- 🧪 Chemistry-based puzzle mechanics
- 🎮 2048/Tetris-inspired gameplay
- 📚 Designed for Grade 9 chemistry learning
- 💻 Available for Windows and Web
